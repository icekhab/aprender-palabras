# Подсказки перевода

## Границы функции

На текущем этапе доступен только поиск пар перевода через OpenAI.
Таблица карточек и объединение подсказок из БД не реализованы.

Поведение:

- пользователь вводит слово, фразу или незавершённый префикс в поиске на главной;
- frontend отправляет запрос после debounce 300 ms и при длине от 2 символов;
- backend определяет направление по наличию кириллицы;
- OpenAI дополняет вероятные полные слова/фразы по префиксу и возвращает до 8 уникальных пар `{ spanish, russian }`;
- в подсказках только словарные формы (леммы): без склонения по роду/числу/падежу и без разворота спряжений одного слова;
- клик по подсказке открывает страницу добавления слова
  `/words/new?spanish=...&russian=...` (см. [words.md](./words.md)).

## Направление перевода

| Ввод | Направление |
|---|---|
| Есть символы кириллицы | русский → испанский |
| Нет кириллицы | испанский → русский |

## REST API

Все маршруты находятся под префиксом `/api`. Требуется активная сессия.

### `GET /suggestions?q=...`

Query-параметр `q`:

- обязателен;
- после `trim` длина от 2 до 100 символов;
- может быть неполным префиксом: модель угадывает завершения и их переводы.

Успешный ответ `200`:

```json
{
  "suggestions": [
    {
      "spanish": "esperar",
      "russian": "ждать"
    }
  ]
}
```

Ошибки:

| Статус | Когда |
|---|---|
| `400` | невалидный `q` |
| `401` | нет сессии |
| `503` | нет `OPENAI_API_KEY` или сбой OpenAI |

## Переменные окружения

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-sol
```

Приложение должно запускаться без ключа OpenAI. В этом случае endpoint
подсказок отвечает `503`, а остальной функционал остаётся доступен.
