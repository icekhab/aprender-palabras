# Подсказки перевода

## Границы функции

Поиск пар перевода через OpenAI, с обогащением из общей таблицы `Word`
и личного словаря (`UserCard`) текущего пользователя.

Поведение:

- пользователь вводит слово, фразу или незавершённый префикс в поиске на главной;
- панель подсказок видна только пока инпут в фокусе; при blur скрывается,
  при повторном focus показывается снова (если запрос ещё достаточно длинный);
- frontend отправляет запрос после debounce 300 ms и при длине от 2 символов;
- backend определяет направление по наличию кириллицы;
- OpenAI дополняет вероятные полные слова/фразы по префиксу и возвращает до 8 уникальных пар `{ spanish, russian }`;
- в подсказках только словарные формы (леммы): без склонения по роду/числу/падежу и без разворота спряжений одного слова;
- backend сопоставляет каждую пару с `Word` по нормализованному ключу;
  при совпадении возвращает `wordId`, а если у пользователя уже есть карточка —
  ещё и `progress`;
- UI:
  - нет `wordId` — у **admin** клик открывает `/words/new?...` (полный
    мастер); у **user** — автогенерация и сразу add (без экрана правки),
    у **teacher**/**admin** — полный мастер;
    с проверкой квоты генераций;
  - есть `wordId`, нет в личном словаре — иконка «+», `POST /words/existing`
    (без платных API, без квоты генераций);
  - уже в личном словаре — иконка прогресса (как в Diccionario).

Дневная квота suggestions для не-admin: дефолт **300**/день (`Europe/Madrid`),
override `User.dailySuggestionsLimit`. См. [quotas.md](./quotas.md).

## Направление перевода

| Ввод | Направление |
|---|---|
| Есть символы кириллицы | русский → испанский |
| Нет кириллицы | испанский → русский |

## REST API

Все маршруты находятся под префиксом `/api`. Требуется активная сессия.

### `GET /suggestions?q=...`

Query-параметр `q`:

- обязателен;
- после `trim` длина от 2 до 100 символов;
- может быть неполным префиксом: модель угадывает завершения и их переводы.

Успешный ответ `200`:

```json
{
  "suggestions": [
    {
      "spanish": "esperar",
      "russian": "ждать",
      "wordId": "word-uuid-or-null",
      "progress": null
    }
  ]
}
```

| Поле | Значение |
|---|---|
| `wordId` | `id` из `Word`, если пара уже есть в общей базе; иначе `null` |
| `progress` | прогресс `UserCard` текущего пользователя (`inDictionary=true`); иначе `null` |

Ошибки:

| Статус | Когда |
|---|---|
| `400` | невалидный `q` |
| `401` | нет сессии |
| `429` | дневная квота suggestions исчерпана (не-admin); OpenAI не вызывать |
| `503` | нет `OPENAI_API_KEY` или сбой OpenAI |

## Переменные окружения

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-sol
```

Приложение должно запускаться без ключа OpenAI. В этом случае endpoint
подсказок отвечает `503`, а остальной функционал остаётся доступен.
