# Слова (глобальная база)

## Границы функции

На текущем этапе:

- suggestions по-прежнему возвращают только пару `{ spanish, russian }` без `id`;
- клик по suggestion открывает страницу добавления слова;
- backend генерирует поля карточки через OpenAI и изображение через Unsplash;
- пользователь просматривает draft в режиме read-only и подтверждает сохранение;
- слово сохраняется в общую таблицу `Word` без привязки к пользователю;
- личный словарь пользователя пока не создаётся;
- на странице добавления есть кнопки прослушивания для испанского слова и
  каждого примера через Web Speech API;
- выбранный испанский голос настраивается в `/settings` и хранится в
  `localStorage` (`aprender-palabras.spanishVoiceURI`); если сохранённый
  голос недоступен, используется первый доступный `es-*`.

## Модель `Word`

Уникальность пары: `normalizedSpanish` + `normalizedRussian`
(trim, схлопывание пробелов, lower case; `ñ` сохраняется).

Поля: испанский текст, основной русский перевод, дополнительные переводы,
определение на испанском, примеры, часть речи, род, по три неверных варианта
каждого направления, URL изображения и атрибуция Unsplash.

## REST API

Все маршруты под префиксом `/api`. Требуется активная сессия.

### `POST /words/preview`

Тело:

```json
{
  "spanish": "esperar",
  "russian": "ждать"
}
```

Ответ `200`: полный draft карточки без записи в БД. Если OpenAI или Unsplash
недоступны, обязательная пара возвращается, опциональные поля остаются пустыми.

### `POST /words`

Тело: тот же draft (включая `imageDownloadLocation` для tracking Unsplash).

Успех `200`: созданное слово с `id` и timestamps.

Ошибки:

| Статус | Когда |
|---|---|
| `400` | невалидное тело |
| `401` | нет сессии |
| `409` | пара уже существует |

## Переменные окружения

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-sol
UNSPLASH_ACCESS_KEY=
```

Нужен только Unsplash Access Key. Secret Key не используется.
Ключи хранятся только на backend.
