# Слова (глобальная база и личный словарь)

## Границы функции

На текущем этапе:

- suggestions по-прежнему возвращают только пару `{ spanish, russian }` без `id`;
- клик по suggestion открывает страницу добавления слова;
- backend генерирует поля карточки через OpenAI и изображение через Unsplash;
- пользователь просматривает draft в режиме read-only и подтверждает сохранение;
- слово сохраняется в общую таблицу `Word` (или переиспользуется, если пара уже есть);
- одновременно создаётся запись `UserCard` в личном словаре текущего пользователя;
- на странице добавления есть кнопки прослушивания для испанского слова и
  каждого примера через Web Speech API;
- выбранный испанский голос настраивается в `/settings` и хранится в
  `localStorage` (`aprender-palabras.spanishVoiceURI`); если сохранённый
  голос недоступен, используется первый доступный `es-*`.

Пока не реализовано: список личного словаря, просмотр/редактирование/удаление
карточек, карточки из уроков.

## Модель `Word`

Уникальность пары: `normalizedSpanish` + `normalizedRussian`
(trim, схлопывание пробелов, lower case; `ñ` сохраняется).

Поля: испанский текст, основной русский перевод, дополнительные переводы,
определение на испанском, примеры, часть речи, род, по три неверных варианта
каждого направления, URL изображения и атрибуция Unsplash.

## Модель `UserCard`

Личная карточка пользователя, ссылающаяся на глобальный `Word`.

| Поле | Описание |
|---|---|
| `userId` + `wordId` | уникальная пара: один пользователь — одна карточка на слово |
| `source` | `manual` (самостоятельно) или `lesson` (на будущее) |
| `inDictionary` | входит ли в личный словарь (`true` для самостоятельного добавления) |
| `progress` | изученность 0–100%, при создании `0` |
| `addedAt` | дата добавления |

Удаление `User` каскадно удаляет его `UserCard`. Удаление `Word` запрещено,
пока на него ссылаются карточки (`ON DELETE RESTRICT`).

## REST API

Все маршруты под префиксом `/api`. Требуется активная сессия.

### `POST /words/preview`

Тело:

```json
{
  "spanish": "esperar",
  "russian": "ждать"
}
```

Ответ `200`: полный draft карточки без записи в БД. Если OpenAI или Unsplash
недоступны, обязательная пара возвращается, опциональные поля остаются пустыми.

### `POST /words`

Тело: тот же draft (включая `imageDownloadLocation` для tracking Unsplash).

Поведение:

1. найти `Word` по нормализованной паре;
2. если нет — создать из draft;
3. если у текущего пользователя уже есть `UserCard` на этот `Word` — `409`;
4. иначе создать `UserCard` с `source=manual`, `inDictionary=true`, `progress=0`.

При переиспользовании существующего `Word` его поля **не** перезаписываются
draft’ом.

Успех `200`: слово (`Word`) с `id` и timestamps. Ответ пока без полей
`UserCard` — список словаря будет отдельным API.

Ошибки:

| Статус | Когда |
|---|---|
| `400` | невалидное тело |
| `401` | нет сессии |
| `409` | карточка уже есть у этого пользователя |

## Переменные окружения

```dotenv
OPENAI_API_KEY=
OPENAI_MODEL=gpt-6-sol
UNSPLASH_ACCESS_KEY=
```

Нужен только Unsplash Access Key. Secret Key не используется.
Ключи хранятся только на backend.
