# Авторизация

## Границы функции

На текущем этапе доступны вход, восстановление серверной сессии и выход.
Самостоятельная регистрация не реализуется. Тестовый пользователь создаётся
миграцией:

- логин: `icekhab@gmail.com`;
- пароль для локального входа: `123345`.

В базе данных хранится только Argon2id-хеш пароля. Логин сравнивается без учёта
регистра.

## Сессии

После успешного входа backend создаёт криптографически случайный непрозрачный
токен. В PostgreSQL хранится только его SHA-256-хеш. Сессия действует 30 дней
с момента входа и не продлевается автоматически.

Токен передаётся cookie `aprender_palabras_session` со свойствами:

- `HttpOnly`;
- `SameSite=Lax`;
- `Path=/`;
- `Secure` в production; локально флаг отключён для работы через HTTP;
- `Expires`, совпадающий со сроком сессии.

Изменяющие запросы принимаются только с заголовком `Origin`, точно совпадающим
с `APP_ORIGIN`. Выход удаляет текущую сессию из БД и очищает cookie.

## REST API

Все маршруты находятся под префиксом `/api`.

### `POST /auth/login`

Публичный маршрут. Принимает JSON:

```json
{
  "login": "icekhab@gmail.com",
  "password": "123345"
}
```

При успехе возвращает `200` и безопасные данные пользователя:

```json
{
  "id": "uuid",
  "login": "icekhab@gmail.com"
}
```

Неизвестный логин и неверный пароль всегда дают одинаковый `401`, чтобы не
раскрывать наличие пользователя. Невалидный JSON даёт `400`, превышение лимита
попыток — `429`. Текст API-ошибок возвращается на английском языке; frontend
показывает пользователю соответствующее сообщение на испанском.

### `GET /auth/me`

Возвращает безопасные данные текущего пользователя. Отсутствующая, неизвестная
или истёкшая сессия даёт `401`.

### `POST /auth/logout`

Удаляет текущую сессию, очищает cookie и возвращает `204`.

## Защита остальных API

Авторизация включена глобально. Публичными являются только маршрут входа и
технический `GET /api/health`, используемый healthcheck контейнера. Текущий
`/api/tests` и все будущие продуктовые маршруты по умолчанию требуют действующую
сессию. Публичные маршруты должны явно отмечаться соответствующим декоратором.
