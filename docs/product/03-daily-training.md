# Прогресс и ежедневные тренажёры

## 1. Цель

Система ежедневно предлагает до пяти тренажёров, совмещая слова из окон уроков
**всех активных курсов** участника с самостоятельно добавленными словами.
При выборе карточек приоритет получают менее изученные и давно не
повторявшиеся слова.

Для каждого участия `accepted` в **эффективно активном** курсе
([05-courses.md](./05-courses.md) §7: `active` и создатель — teacher/admin)
берётся окно `предыдущие + текущий + следующий`. Окна объединяются.
Неэффективные курсы, `pending` и `completed` не дают уроковое окно; карточки
уже в словаре по-прежнему участвуют в пуле как словарь.

После прохождения ежедневных тренажёров пользователь может запускать
дополнительные случайные тренажёры.

## 2. Прогресс карточки

Прогресс принадлежит комбинации `пользователь + карточка`. Если карточка входит в несколько уроков, во всех местах показывается одно значение прогресса.

Для алгоритма хранятся агрегаты:

- прогресс от 0 до 100%;
- дата и время последней завершённой тренировки с карточкой;
- количество завершённых тренажёров с карточкой;
- количество показов карточки в завершённых тренажёрах.

История отдельных ответов не является бизнес-требованием первой версии.

## 3. Изменение прогресса

Ошибки считаются отдельно для каждой карточки в пределах одного завершённого тренажёра.

Ошибкой считается:

- выбор неправильного варианта;
- ввод неправильного испанского текста;
- выбор «не помню»;
- неправильная повторная попытка.

Изменение после полного завершения:

| Ошибки по карточке | Изменение |
|---:|---:|
| 0 | +20 процентных пунктов |
| 1 | +10 процентных пунктов |
| 2 | −10 процентных пунктов |
| 3 и более | −20 процентных пунктов |

Результат ограничивается диапазоном 0–100%.

Примеры:

- `90 + 20 = 100`;
- `95 + 10 = 100`;
- `5 − 10 = 0`;
- `10 − 20 = 0`.

Изменение применяется один раз для каждой карточки после завершения всего тренажёра. Если пользователь закрыл или прервал тренажёр, прогресс и агрегаты не изменяются, а следующий запуск начинается заново.

Если одна карточка встретилась в двух полностью завершённых тренажёрах одного дня, прогресс изменяется после каждого.

## 4. Сброс

Пользователь может сбросить прогресс отдельной карточки после подтверждения:

- прогресс становится 0%;
- дата последней тренировки и агрегатные счётчики сохраняются;
- уже созданные ежедневные подборки не перестраиваются.

## 5. Готовность карточки

В подборки включаются только карточки, которые:

- доступны данному пользователю;
- не удалены;
- входят в личный словарь;
- готовы ко всем упражнениям по правилам карточки.

Исключение — прямой запуск урока: он может использовать подготовленные карточки этого урока, ещё не добавленные в словарь.

## 6. Общий порядок ежедневного формирования

### 6.1. Момент создания

При первом открытии раздела обучения в новый календарный день по `Europe/Madrid` система:

1. собирает подходящие карточки;
2. формирует до пяти подборок по правилам ниже;
3. сохраняет состав и порядок карточек;
4. при последующих открытиях в этот день возвращает тот же набор.

Новые или отредактированные карточки после создания набора не перестраивают его. Они могут попасть в дополнительный тренажёр или в набор следующего дня.

Удалённая либо потерявшая готовность карточка исключается перед запуском ещё не начатого тренажёра и по возможности заменяется из основной или резервной категории.

### 6.2. Размер

- максимум — 12 карточек; при наличии кандидатов набирается до 12;
- допустимый минимум — 1;
- при нехватке основной категории подборка дополняется резервными категориями;
- если во всём словаре нет ни одной готовой карточки, тренажёры не создаются;
- если уникальных карточек достаточно лишь для части из пяти тренажёров, создаётся доступное количество; недостающие слоты не показываются.

### 6.3. Приоритет внутри категории

Для слотов 1–3 и 5 карточки сортируются по следующим ключам:

1. меньший прогресс;
2. более давняя последняя тренировка; никогда не тренировавшиеся идут раньше;
3. меньшее количество показов;
4. случайный порядок для полностью равных кандидатов.

Для **Repaso lejano** (слот 4): только меньший прогресс; при равном прогрессе — случайный порядок.

### 6.4. Повтор между подборками

Карточка не повторяется в двух подборках одного дня. Если в пуле слота не осталось неиспользованных сегодня кандидатов, слот не создаётся (добивка из других категорий и повторы запрещены).

## 7. Категории при наличии текущего урока (в активных курсах)

Если у пользователя несколько активных курсов с выбранным текущим уроком,
множества L0 / L1–L4 / следующего урока — **объединения** соответствующих
множеств по каждому такому курсу.

Обозначения (в рамках одного курса, затем объединение):

- **L0** — текущий урок курса;
- **L1–L4** — от одного до четырёх уроков непосредственно перед текущим;
- **Started** — `completedTrainerCount > 0`;
- **Unstarted** — `completedTrainerCount = 0`;
- **Якорь** — `lastCompletedTrainerAt` пользователя; если тренировок ещё не было — текущий момент;
- **Recent-14** — `anchor − addedAt < 14 суток`;
- **Age&lt;28** — возраст добавления относительно якоря меньше 28 суток.

**Поток новых слов:** Unstarted попадают **только** в тренажёр 5 (в том числе слова текущего и прошлых уроков). Тренажёры 1–4 содержат только Started. Резерв «весь словарь» не используется: нет кандидатов в пуле — слот не создаётся. Повторы одного слова между слотами одного дня не допускаются.

### Тренажёры 1–2 — Lección actual

Пул:

- L0 ∩ Started;
- Manual ∩ Recent-14 ∩ Started.

До двух слотов без пересечения слов. Нет уникальных — слот не создаётся.

### Тренажёр 3 — Lecciones recientes

Пул:

- L1–L4 ∩ Started;
- Started ∩ Age&lt;28.

### Тренажёр 4 — Repaso lejano

Пул: Started с `anchor − lastTrainedAt ≥ 28 суток`. Приоритет только по прогрессу; при равном прогрессе — случайно (§6.3).

### Тренажёр 5 — Nuevas y próxima lección

Пул: все Unstarted (включая текущий/пройденные уроки и следующий урок, если ещё не учили), от новых к старым по `addedAt`. Нет Unstarted — слот не создаётся.

## 8. Категории без урокового окна

Раздел применяется, когда ни в одном активном курсе у участника нет
выбранного текущего урока (или нет активных курсов с accepted). Тогда
уроковые множества пусты; остаются самостоятельные карточки словаря:

1–2. **Palabras empezadas:** Started ∩ Recent-14 (от якоря), два слота без повторов.  
3. **Recientes:** Started ∩ Age&lt;28.  
4. **Repaso lejano:** Started с давностью тренировки ≥ 28 суток от якоря (прогресс, затем random).  
5. **Palabras nuevas:** все Unstarted.

## 9. Сохранённое состояние дня

На главном экране для каждого ещё не пройденного тренажёра показывается:

- у ежедневных — стабильный номер слота (`slot`), заданный при создании набора дня; после скрытия пройденных слотов номера оставшихся не пересчитываются;
- у дополнительного (extra) номера нет;
- краткое описание источника слов;
- количество карточек.

Состояния в данных: `не начат` или `завершён`. Завершённые ежедневные тренажёры с главной скрываются. Недоступные слоты не создаются и не показываются.

Поскольку прерванный тренажёр не сохраняется, состояния «в процессе» между запусками нет. После возврата он снова отображается как «не начат».

Завершённый ежедневный тренажёр в этот день повторно не запускается. В новый день создаётся новый набор независимо от того, сколько тренажёров предыдущего дня было завершено.

## 10. Дополнительный случайный тренажёр

После завершения всех созданных ежедневных тренажёров на главной показывается один блок дополнительной случайной тренировки. Если часть из пяти не была создана из-за нехватки карточек, достаточно завершить все созданные.

Дополнительный тренажёр:

- содержит до 12 карточек, минимум 1;
- может запускаться неограниченное количество раз (после прохождения текущего extra формируется следующий);
- изменяет прогресс по обычным правилам;
- может включать карточки, уже встречавшиеся сегодня;
- отдаёт таким карточкам более низкий приоритет, но не исключает их.

### Мягкий случайный приоритет

У каждой готовой карточки есть ненулевой шанс выбора. Рекомендуемый продуктовый вес:

`вес = 1 + (100 − прогресс) / 20`

Таким образом, вес находится от 1 до 6. Если карточка уже была в любом тренажёре сегодня, её вес делится на 3. Выбор выполняется случайно без повторов внутри одного тренажёра.

Это правило обеспечивает преимущество менее изученных слов, но не превращает дополнительный тренажёр в жёсткую сортировку.

## 11. Пустые и ошибочные состояния

| Ситуация | Поведение |
|---|---|
| В словаре 0 готовых карточек | Показать приглашение добавить/дополнить карточки |
| Готово 1+ карточек | Создать доступные тренажёры (1–12 слов в каждом) |
| Нельзя создать все пять уникально | Сначала создать уникальные; затем разрешить повторы для минимума 1 |
| После повторов очередной тренажёр всё равно пуст | Не создавать слот |
| Все созданные дневные завершены | Показать один блок дополнительной случайной тренировки |
| Генерация набора завершилась ошибкой | Не сохранять частичный новый день, разрешить повтор |
| Карточка удалена после создания дня | Заменить перед стартом, если возможно |
| Карточка после редактирования перестала быть готовой | Заменить перед стартом по тем же правилам, что удалённую |
| Новый календарный день наступил при открытой странице | При следующем входе в раздел загрузить новый день |

## 12. Критерии приёмки

- **DAILY-01:** прогресс всегда находится в диапазоне 0–100%.
- **DAILY-02:** 0/1/2/3+ ошибки изменяют прогресс на +20/+10/−10/−20.
- **DAILY-03:** «не помню» и каждая неправильная повторная попытка считаются ошибками.
- **DAILY-04:** прерванный тренажёр не изменяет прогресс, дату и счётчики.
- **DAILY-05:** набор создаётся один раз за день `Europe/Madrid` и повторно загружается без перестановки.
- **DAILY-06:** тренажёр содержит до 12 карточек при наличии кандидатов и создаётся при минимум 1 карточке.
- **DAILY-07:** сначала используются уникальные карточки дня, повторы имеют низший приоритет.
- **DAILY-08:** внутри слотов 1–3 и 5 меньший прогресс имеет больший приоритет, затем давность и показы; в Repaso lejano — только прогресс, иначе random.
- **DAILY-09:** слоты 1–3 используют заданные диапазоны уроков и возраст самостоятельных карточек.
- **DAILY-10:** слот 4 (Repaso lejano) — Started с `anchor − lastTrainedAt ≥ 28 суток`.
- **DAILY-11:** слот 5 отдаёт преимущество Unstarted (новые и следующий урок).
- **DAILY-12:** без урокового окна активных курсов применяются пять временных
  категорий самостоятельных карточек.
- **DAILY-17:** пул объединяет окна prev+current+next эффективно активных
  курсов с `accepted`; словарь (в т.ч. из деактивированных курсов) остаётся.
- **DAILY-13:** завершённый ежедневный тренажёр повторно в этот день не запускается.
- **DAILY-14:** после завершения доступных ежедневных тренажёров можно неограниченно запускать дополнительные.
- **DAILY-15:** дополнительный тренажёр использует мягкий случайный приоритет и может с меньшим весом повторять сегодняшние карточки.
- **DAILY-16:** сброс карточки устанавливает прогресс 0%, не перестраивая текущий день.
