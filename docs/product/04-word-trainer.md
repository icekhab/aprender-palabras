# Тренажёр слов

## 1. Цель

Тренажёр знакомит пользователя с карточками, а затем проверяет узнавание перевода, восприятие на слух и воспроизведение испанского написания. Ошибочные задания повторяются, а после полного завершения обновляется прогресс каждой карточки.

## 2. Источники запуска

Один механизм тренажёра используется для:

- шести ежедневных подборок;
- дополнительных случайных подборок;
- прямого запуска урока.

Источник определяет набор карточек, но не меняет упражнения, подсчёт ошибок и прогресс.

## 3. Предусловия

Для запуска необходимо:

- от 4 до 10 готовых карточек;
- доступный на устройстве испанский Web Speech-голос;
- отсутствие удалённых карточек в наборе после проверки перед стартом.

Если условий нет, запуск блокируется с конкретным объяснением и ссылкой на действие, которое может исправить проблему.

## 4. Общая структура

Тренажёр состоит из:

1. знакомства с карточками первой тренировки (по группам, перед их первой проверкой);
2. пяти проверочных упражнений для каждой карточки;
3. адаптивных повторов после ошибок;
4. итогового экрана;
5. атомарного обновления прогресса после завершения.

Вводная карточка не является проверочным упражнением и не влияет на количество ошибок.

## 5. Этап знакомства

Знакомство показывается **только для карточек с первой тренировкой** (`completedTrainerCount = 0` / `showIntro = true`). Слова, уже участвовавшие хотя бы в одном завершённом тренажёре, intro пропускают.

Intro **не** собирается в один общий блок в начале запуска. Для каждой группы слов (см. §7) intro этой группы показывается сразу перед её первым проверочным упражнением, в случайном порядке внутри группы. Если в группе нет слов с `showIntro`, intro для группы пропускается. Если таких слов нет во всём наборе, знакомство не появляется вовсе.

Карточка показывает:

- изображение либо заглушку;
- испанский текст;
- часть речи и род компактно под словом (если есть);
- основной русский перевод;
- определение, если есть;
- 2–3 примера, если есть.

При открытии карточки испанский текст автоматически воспроизводится выбранным голосом. Пользователь может:

- повторно воспроизвести слово;
- отдельно воспроизвести каждый пример;
- перейти к следующей карточке кнопкой «Vale».

Автоматический переход по таймеру не используется.

Выход из тренажёра — кнопкой «назад» с подтверждением: пользователь предупреждается, что потеряет прогресс по этой тренировке.

## 6. Типы упражнений

### Упражнение 1. Испанский → русский, выбор

Показывается испанский текст и автоматически воспроизводится его аудио. Пользователь может повторить аудио.

Показываются четыре случайно расположенных ответа:

- основной русский перевод;
- три сохранённых неверных русских варианта.

Правильный ответ один.

### Упражнение 2. Аудио → самооценка

Даётся **только** карточкам с `completedTrainerCount <= 2` (на момент старта запуска). При `completedTrainerCount >= 3` тип 2 в личную цепочку не входит (см. §7).

Текст, перевод и изображение до ответа не показываются. Автоматически воспроизводится испанский текст; аудио можно повторить.

Доступны ответы:

- «Recuerdo» / «Помню»;
- «No recuerdo» / «Не помню».

Ответ на упражнение 2 **не** создаёт повторов в очереди и **не** влияет на число ошибок карточки и прогресс (§10.2, §12). После любого ответа показывается карточка слова (без баннера «неправильно»).

### Упражнение 3. Русский → испанский, выбор

Показывается основной русский перевод. Показываются четыре случайно расположенных ответа:

- испанский текст карточки;
- три сохранённых неверных испанских варианта.

Аудио до ответа не воспроизводится.

### Упражнение 4. Аудио → ввод на испанском

До ответа показывается только управление аудио. Пользователь вводит услышанный испанский текст.

### Упражнение 5. Русский → ввод на испанском

Показывается основной русский перевод. Пользователь вводит испанский текст. Подсказки и аудио до ответа недоступны.

## 7. Порядок упражнений

### 7.1. Деление на группы

В начале запуска все карточки случайно перемешиваются один раз и нарезаются на группы по **не более пяти** слов. Последняя группа может быть короче (например, 12 слов → 5 + 5 + 2).

Состав групп не меняется до конца запуска. Повторы ошибок в новые группы не пересобираются (см. §10).

### 7.2. Личные цепочки и раунды групп

У каждой карточки — **личная цепочка типов**, фиксируется один раз при старте запуска:

- префикс: тип 1, затем тип 2 если `completedTrainerCount <= 2` (иначе тип 2 пропускается);
- дальше — **случайная перестановка** типов 3, 4 и 5 (не строгий порядок `3 → 4 → 5`).

Примеры: `1 → 2 → 5 → 3 → 4` или `1 → 4 → 3 → 5` (без типа 2).

Расписание групп двигает **раунды**, а не глобальный тип: в раунде N группа выдаёт N-й элемент личной цепочки каждого слова. В одном раунде типы могут **миксоваться** (например, упр. 2 и упр. 3 вместе). Слова с короткой цепочкой в поздних раундах не участвуют. Порядок шагов внутри раунда случайный и фиксируется при создании раунда.

Стартовая раскладка (bootstrap):

1. группа 0: intro (если нужно) → раунд 1 → раунд 2;
2. для каждой следующей группы `g = 1 … n−1`:
   - intro группы `g` (если нужно) → раунд 1;
   - если это не последняя группа и у группы 0 ещё есть раунды — группа 0 выполняет следующий раунд;
3. далее round-robin по ещё не завершённым группам в порядке  
   `группа 1 → группа 0 → группа 2 → группа 3 → …`.

Пример для трёх групп, когда все карточки eligible для типа 2 (без intro):

`G0:r1 → G0:r2 → G1:r1 → G0:r3 → G2:r1 → G1:r2 → G0:r4 → G2:r2 → G1:r3 → G0:r5 → G2:r3 → G1:r4 → G2:r4 → G1:r5 → G2:r5`

Одна группа: intro (если нужно), затем её раунды подряд.

## 8. Проверка текстового ответа

Перед сравнением:

- удаляются пробелы в начале и конце;
- последовательности пробелов заменяются одним пробелом;
- регистр не учитывается.

Правила символов:

- `ñ` обязательна: замена на `n` является ошибкой;
- ударения над `á`, `é`, `í`, `ó`, `ú` необязательны;
- отсутствие или неправильное ударение при прочем совпадении считается правильным ответом с предупреждением;
- предупреждение показывает правильное написание;
- другие опечатки не принимаются;
- перестановка слов не принимается;
- артикль обязателен, если сохранён как часть испанского текста;
- иные символы, дефисы и апострофы должны совпадать.

Пустой ответ отправить нельзя.

## 9. Обратная связь после ответа

После каждого ответа открывается состояние результата, в котором:

- указано «Правильно» или «Неправильно»;
- при необходимости показано предупреждение об ударении;
- показана полная карточка;
- выделен правильный ответ;
- испанский текст автоматически воспроизводится;
- доступны повтор аудио слова и примеров;
- есть явное действие продолжения.

Пользователь не может изменить уже отправленный ответ.

## 10. Повторы ошибок

### 10.1. Общие упражнения

Для упражнений 1, 3, 4 и 5:

1. после первой ошибки то же упражнение той же карточки **добавляется в конец плоской очереди** запуска;
2. после второй ошибки оно ещё раз добавляется в конец очереди;
3. после третьей ошибки правильный ответ показывается, новых повторов не создаётся.

Повторы **не** пересобираются в группы и не меняют порядок базовых блоков: только append в конец, в том числе повтор после повторной ошибки.

Максимум — три попытки одного типа упражнения для одной карточки за запуск. Варианты выбора при повторе снова перемешиваются.

Все неправильные попытки учитываются в общем количестве ошибок карточки. Правильная повторная попытка не отменяет предыдущую ошибку.

### 10.2. Упражнение 2 (самооценка)

Упражнение 2 **не участвует** в механике повторов §10.1:

- ни «Recuerdo», ни «No recuerdo» не добавляются в конец очереди;
- самооценка не вставляется повторно перед другими упражнениями карточки;
- ответы не увеличивают и не уменьшают счётчик ошибок карточки и не влияют на формулу прогресса (§12).

Самооценка выполняется один раз за запуск (если тип 2 есть в личной цепочке) и после ответа сессия просто переходит к следующему шагу очереди.

## 11. Очередь и счётчик выполнения

Интерфейс показывает:

- текущий номер выполненного задания;
- минимальное оставшееся количество заданий;
- количество карточек в тренажёре.

Общее количество заданий может увеличиться из-за ошибок, поэтому нельзя показывать неизменяемый знаменатель вида `12 из 40` как гарантированный итог. Допустимы формулировки `Выполнено 12` и `Осталось минимум 28`.

Пользователь не может пропустить проверочное задание.

## 12. Завершение и прогресс

Тренажёр считается завершённым, когда:

- выполнена базовая последовательность;
- обработаны все созданные повторы;
- показана обратная связь последнего задания.

На итоговом экране для каждой карточки показываются:

- количество ошибок;
- старый прогресс;
- изменение;
- новый прогресс.

Применяется формула из [документа прогресса](./03-daily-training.md):

- 0 ошибок: +50;
- 1 ошибка: +30;
- 2 ошибки: +10;
- 3 и более: −10.

В число ошибок карточки входят только упражнения 1, 3, 4 и 5. Ответы упражнения 2 не учитываются.

Обновление всех карточек и статуса тренажёра выполняется как единый результат. Если результат не удалось сохранить:

- пользователь видит ошибку;
- может повторить сохранение;
- тренажёр не помечается завершённым;
- частично обновлённый прогресс недопустим.

## 13. Прерывание

Текущее прохождение не сохраняется между запусками.

Прерыванием считаются:

- явный выход из тренажёра после подтверждения;
- обновление страницы;
- закрытие вкладки или приложения;
- переход по маршруту, уничтожающий состояние тренажёра;
- удаление участвующей карточки.

После прерывания:

- все ответы текущего запуска отбрасываются;
- прогресс и агрегаты не меняются;
- ежедневный тренажёр остаётся незавершённым;
- следующий запуск начинается с этапа знакомства и новым перемешиванием.

Пока страница и состояние приложения не уничтожены, кратковременная блокировка экрана или сворачивание приложения не обязаны сбрасывать запуск.

## 14. Доступность и состояния

- Все действия должны быть доступны с клавиатуры.
- Выбранный вариант не должен обозначаться только цветом.
- Автовоспроизведение сопровождается видимой кнопкой повтора.
- Во время воспроизведения должна быть видимая индикация.
- После отправки ответа кнопки блокируются до отображения результата.
- Повторная отправка одного ответа не должна создавать две попытки.
- При ошибке Web Speech до ответа пользователь может повторить воспроизведение; если звук получить невозможно, тренажёр нужно прервать без изменения прогресса.

## 15. Критерии приёмки

- **TRAIN-01:** тренажёр нельзя запустить с менее чем четырьмя готовыми карточками.
- **TRAIN-02:** intro показывается только для слов с `showIntro` / `completedTrainerCount = 0`, сразу перед первым упражнением их группы, с автоозвучкой испанского текста.
- **TRAIN-03:** карточка с `completedTrainerCount <= 2` получает типы 1–5; иначе типы 1, 3, 4, 5 (без типа 2); порядок типов 3–5 случайный на запуск.
- **TRAIN-04:** слова нарезаются на группы ≤5; раунды идут по bootstrap + round-robin из §7.2; в одном раунде типы могут миксоваться.
- **TRAIN-05:** в заданиях выбора показываются три сохранённых неверных и один правильный вариант.
- **TRAIN-06:** порядок четырёх вариантов случайный, правильный ответ только один.
- **TRAIN-07:** после каждого ответа показывается полная карточка, результат и аудио.
- **TRAIN-08:** первая и вторая ошибки упражнений 1, 3, 4, 5 создают повтор в конце; третья не создаёт.
- **TRAIN-09:** упражнение 2 не создаёт повторов в очереди.
- **TRAIN-10:** ответы упражнения 2 не влияют на число ошибок карточки и на прогресс.
- **TRAIN-11:** регистр и ударения не создают ошибку, но пропущенное ударение создаёт предупреждение.
- **TRAIN-12:** `n` вместо `ñ`, другая опечатка или пропущенный обязательный артикль являются ошибкой.
- **TRAIN-13:** в расчёт прогресса входят только неправильные попытки упражнений 1, 3, 4 и 5.
- **TRAIN-14:** прогресс изменяется только после полного завершения.
- **TRAIN-15:** прерванный запуск начинается заново и не влияет на прогресс.
- **TRAIN-16:** результат сохраняется целиком; частичное обновление карточек невозможно.
- **TRAIN-17:** после завершения показываются ошибки и изменение прогресса каждой карточки.
