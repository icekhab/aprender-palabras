# Слова и карточка слова

## 1. Цель

Пользователь может создать отдельную карточку для конкретного значения испанского слова, словосочетания или выражения, проверить автоматически предложенные данные и сохранить карточку в личном словаре либо в уроке.

## 2. Состав карточки

| Поле | Обязательное | После сохранения | Источник |
|---|---:|---|---|
| Испанский текст | Да | Нельзя редактировать | Пользователь |
| Основной русский перевод | Да | Можно редактировать (глобально для всех) | БД, AI или пользователь |
| Дополнительные переводы | Нет | Не показываются в UI | AI |
| Определение на испанском | Да (при редактировании) | Можно редактировать | AI или пользователь |
| 2–3 коротких примера на испанском | Да ≥2 (при редактировании) | Можно редактировать | AI или пользователь |
| URL изображения | Нет | Можно изменить и перегенерировать | Unsplash или пользователь |
| Данные об авторе/источнике изображения | Обязательны для Unsplash | Обновляются вместе с URL | Unsplash |
| Часть речи | Да (при редактировании, из списка) | Можно редактировать | AI или пользователь |
| Род существительного | Да для `sustantivo` | Можно редактировать | AI или пользователь |
| До 10 неверных русских вариантов | ≥3 | Можно редактировать | AI или пользователь |
| До 10 неверных испанских вариантов | ≥3 | Можно редактировать | AI или пользователь |

Четвёртый вариант для задания не хранится как неверный:

- в задании `испанский → русский` правильным четвёртым вариантом является основной русский перевод;
- в задании `русский → испанский` правильным четвёртым вариантом является испанский текст карточки.

В интерфейсе четыре ответа всегда перемешиваются.

## 3. Правила значений и дубликатов

### 3.1. Отдельное значение

Одна карточка описывает ровно одно изучаемое значение. Нельзя объединять в одной карточке два основных перевода.

Дополнительные переводы являются формулировками того же значения, а не другими значениями слова.

Корректно:

- основной перевод: `ждать`;
- дополнительные: `ожидать`, `дожидаться`.

Некорректно:

- основной перевод: `ждать`;
- дополнительный перевод: `надеяться`.

### 3.2. Определение дубликата

Дубликатом в пределах одного пользователя считается совпадение:

- испанского текста;
- основного русского перевода.

Для проверки удаляются пробелы в начале и конце, повторяющиеся пробелы заменяются одним, регистр не учитывается. Диакритические символы не удаляются: `n` и `ñ` различаются.

Проверка выполняется среди всех карточек пользователя, включая подготовленные карточки будущих уроков.

Совпадение нового основного перевода с дополнительным переводом существующей карточки считается предупреждением о возможном дубликате, но не блокирует создание автоматически: одинаковая формулировка может обозначать другое значение в другом контексте. Пользователь должен выбрать «Открыть существующую» либо явно подтвердить «Это другое значение».

Если дубликат найден:

1. новая карточка не создаётся;
2. пользователь получает сообщение;
3. открывается существующая карточка;
4. при добавлении из урока существующая карточка связывается с уроком.

Основной перевод сохранённой карточки можно изменить на экране редактирования;
изменение применяется ко всем пользователям с этой карточкой. Для другого
значения того же испанского слова создаётся новая карточка.

## 4. Добавление самостоятельной карточки

### 4.1. Предусловия

- пользователь авторизован;
- пользователь открыл действие «Добавить слово»;
- направление автоматически установлено как `испанский → русский`.

### 4.2. Шаг 1. Ввод испанского текста

Пользователь вводит слово, словосочетание или выражение. Пустое значение и строка только из пробелов не принимаются.

После продолжения система:

1. нормализует пробелы для поиска, не меняя сохранённое написание;
2. ищет совпадения среди всех карточек пользователя, включая подготовленные карточки уроков;
3. получает известные переводы из общей обезличенной базы;
4. запрашивает варианты перевода у AI;
5. объединяет результаты без точных повторов.

### 4.3. Шаг 2. Выбор перевода

Варианты показываются группами и в следующем порядке:

1. переводы, уже известные базе данных;
2. новые варианты AI.

Один и тот же перевод показывается один раз, с приоритетом источника «БД». Пользователь может:

- выбрать вариант;
- ввести собственный основной перевод;
- повторить AI-запрос после ошибки.

Если выбранная пара уже есть в личном словаре, применяется сценарий дубликата и генерация не запускается.

### 4.4. Шаг 3. Генерация содержимого

После выбора основного перевода система запрашивает у AI все связанные текстовые данные одним структурированным ответом:

- дополнительные переводы того же значения;
- определение на испанском;
- 2–3 коротких контекстных примера;
- часть речи;
- род, если это существительное;
- не менее 3 неверных русских вариантов (AI обычно даёт 10);
- не менее 3 неверных испанских вариантов (AI обычно даёт 10);
- поисковую фразу для Unsplash.

Получение вариантов перевода до выбора значения и получение содержимого после выбора являются двумя разными бизнес-шагами. Техническая документация может оптимизировать число сетевых запросов, но интерфейс обязан сохранить этот порядок.

AI-ответ считается пригодным только после проверки структуры. Отсутствующее или некорректное необязательное поле остаётся пустым и не блокирует форму.

### 4.5. Шаг 4. Изображение

По поисковой фразе выполняется поиск Unsplash. Система предлагает одно изображение и сохраняет:

- URL изображения;
- имя и URL профиля автора;
- URL страницы изображения;
- название и URL Unsplash для обязательной атрибуции.

После принятия изображения система регистрирует его использование способом, требуемым Unsplash API. Это происходит без дополнительного действия пользователя.

Пользователь может:

- принять изображение;
- запросить другое;
- вставить собственный URL;
- оставить изображение пустым.

На первом этапе файл изображения не копируется в собственное хранилище. Если внешний URL перестал работать, показывается заглушка и действие замены/перегенерации.

### 4.6. Шаг 5. Проверка и сохранение

Перед сохранением пользователь видит редактируемую форму (как на edit): можно
менять испанский, перевод и остальные обязательные поля, перегенерировать
изображение. Если AI не ответил, форма открывается с парой из поиска и
заполняется вручную.

Сохранение на add/edit требует тех же обязательных полей (перевод, definición,
≥2 ejemplos, categoría, género для sustantivo, ≥3 wrong options с каждой
стороны). Изображение необязательно.

Самостоятельная карточка сразу получает:

- принадлежность текущему пользователю;
- источник «самостоятельно добавлена»;
- дату добавления;
- членство в личном словаре;
- начальный прогресс 0%.

## 5. Готовность к тренажёру

Карточка готова к полному тренажёру, если заполнены:

- испанский текст;
- основной русский перевод;
- не менее 3 уникальных неверных русских вариантов;
- не менее 3 уникальных неверных испанских вариантов.

В задании выбора из пула показываются 3 случайных неверных варианта и один правильный.

Изображение, определение и примеры улучшают вводную карточку, но не обязательны для допуска.

### Требования к неверным вариантам

1. Все три варианта одного направления уникальны без учёта регистра и лишних пробелов.
2. Неверный вариант не совпадает с правильным ответом.
3. Русский неверный вариант не может совпадать с дополнительным правильным переводом.
4. В рамках изучаемого значения неверный вариант не должен быть ещё одним правильным ответом.
5. Пустой вариант не принимается.

Интерфейс показывает статус «Готово к тренировке» или список отсутствующих/некорректных полей.

## 6. Просмотр карточки

Карточка показывает:

- испанский текст;
- основной и дополнительные переводы;
- изображение и атрибуцию;
- часть речи и род;
- определение;
- примеры;
- прогресс 0–100%;
- уроки, в которые она добавлена;
- статус готовности к тренажёру.

Доступные действия:

- воспроизвести испанский текст;
- воспроизвести каждый пример;
- изменить разрешённые поля;
- перегенерировать определение;
- заменить/перегенерировать изображение;
- сбросить прогресс;
- удалить карточку.

## 7. Аудио и настройка голоса

### 7.1. Общие правила

1. Аудиофайлы не создаются и не сохраняются.
2. Web Speech API получает сохранённый испанский текст непосредственно перед воспроизведением.
3. Для слова и каждого примера есть отдельная кнопка воспроизведения.
4. Повторное нажатие перезапускает соответствующее воспроизведение.

### 7.2. Выбор голоса

В настройках показываются только доступные на устройстве голоса, язык которых является испанским (`es-*`). Пользователь выбирает один голос.

Если ранее выбранный голос недоступен:

1. система выбирает первый доступный испанский голос;
2. пользователь получает ненавязчивое сообщение;
3. новая настройка сохраняется только после явного выбора пользователя.

Если испанских голосов нет, текстовые функции карточки остаются доступны, но запуск полного тренажёра блокируется с объяснением, поскольку часть заданий является только аудиальной.

## 8. Редактирование

Со страницы карточки (`/words/:cardId`) иконка карандаша открывает
`/words/:cardId/edit`.

Можно редактировать:

- основной русский перевод (изменение пишется в общий `Word` и видно всем
  пользователям с этой карточкой);
- определение;
- примеры (≥2);
- часть речи (выпадающий список) и род (только для `sustantivo`);
- URL и атрибуцию изображения;
- пул неверных вариантов каждого направления (3–10).

Нельзя редактировать испанский текст.

При смене русского перевода система проверяет уникальность пары
`(испанский, русский)`. Конфликтующее изменение не сохраняется (`409`).

Сохранение на экране редактирования требует заполнения обязательных полей
(перевод, определение, ≥2 примеров, категория, род для существительного,
≥3 неверных варианта в каждую сторону). Изображение необязательно.

Перегенерация изображения («Otra imagen») учитывает текущий перевод в форме,
заменяет превью URL и атрибуцию; в БД попадает только после «Guardar».
Другие поля автоматически не меняются.

## 9. Удаление и сброс прогресса

### 9.1. Удаление

Перед удалением показывается подтверждение с предупреждением. После подтверждения карточка:

- удаляется из личного словаря;
- удаляется из всех уроков пользователя;
- больше не участвует в будущих подборках;
- исключается из ещё не начатых тренажёров с дополнением по правилам соответствующей подборки, если подходящая замена существует.

Если карточка присутствует в уже начатом тренажёре, тренажёр прекращается и при следующем запуске начинается заново. Прогресс незавершённого запуска не учитывается.

Удаление пользовательской карточки не удаляет обезличенную пару перевода из общей базы, если она используется другими карточками.

### 9.2. Сброс прогресса

Сброс требует подтверждения и устанавливает прогресс карточки в 0%. Дата последней тренировки и агрегатные счётчики сохраняются. Состав уже созданных ежедневных подборок не меняется.

## 10. Ошибки и пограничные случаи

| Ситуация | Поведение |
|---|---|
| AI недоступен при поиске переводов | Показать переводы БД и ручной ввод |
| AI недоступен при генерации карточки | Оставить поля пустыми, разрешить ручное заполнение и повтор |
| AI вернул невалидную структуру | Не переносить сомнительные значения в форму; показать ошибку повтора |
| Unsplash недоступен | Разрешить URL вручную или карточку без изображения |
| URL изображения не открывается | Показать заглушку и действия замены |
| Пользователь дважды отправил форму | Создать не более одной карточки |
| Найден дубликат | Не создавать новую карточку, открыть существующую |
| Нет испанского Web Speech-голоса | Не блокировать карточку; блокировать полный тренажёр |
| AI предложил два правильных ответа среди вариантов | Не считать карточку готовой, потребовать исправить варианты |

## 11. Критерии приёмки

- **WORD-01:** пустой испанский текст нельзя отправить на следующий шаг.
- **WORD-02:** варианты из БД отображаются раньше вариантов AI.
- **WORD-03:** пользователь может выбрать предложенный или ввести собственный перевод.
- **WORD-04:** дубликат не создаётся и открывается существующая карточка.
- **WORD-05:** разные основные значения одного испанского текста сохраняются отдельными карточками.
- **WORD-06:** после выбора перевода связанные поля приходят одним структурированным AI-ответом.
- **WORD-07:** сбой AI или Unsplash не препятствует сохранению обязательных полей.
- **WORD-08:** после сохранения основной перевод можно изменить глобально; конфликт пары блокируется.
- **WORD-09:** у карточки есть пул неверных вариантов (AI — до 10); в задании показываются три случайных плюс правильный четвёртый.
- **WORD-10:** четыре ответа перемешиваются при каждом задании.
- **WORD-11:** карточка с неполными вариантами видна в словаре, но не попадает в полный тренажёр.
- **WORD-12:** Unsplash-изображение хранится как URL с атрибуцией.
- **WORD-13:** слово и примеры воспроизводятся выбранным испанским Web Speech-голосом.
- **WORD-14:** определение и изображение можно независимо перегенерировать.
- **WORD-15:** сброс прогресса устанавливает 0%, не удаляя карточку.
- **WORD-16:** удалённая карточка перестаёт участвовать в уроках и подборках.
