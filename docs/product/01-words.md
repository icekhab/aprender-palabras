# Слова и карточка слова

## 1. Цель

Пользователь может создать отдельную карточку для конкретного значения испанского слова, словосочетания или выражения, проверить автоматически предложенные данные и сохранить карточку в личном словаре либо в уроке.

## 2. Состав карточки

| Поле | Обязательное | После сохранения | Источник |
|---|---:|---|---|
| Испанский текст | Да | Нельзя редактировать | Пользователь |
| Основной русский перевод | Да | Можно редактировать при праве на слово (см. §3); изменение глобально | БД, AI или пользователь |
| Дополнительные переводы | Нет | Не показываются в UI | AI |
| Определение на испанском | Да (при редактировании) | Можно редактировать | AI или пользователь |
| 2–3 коротких примера на испанском | Да ≥2 (при редактировании) | Можно редактировать | AI или пользователь |
| URL изображения | Нет | Можно изменить и перегенерировать | Unsplash или пользователь |
| Данные об авторе/источнике изображения | Обязательны для Unsplash | Обновляются вместе с URL | Unsplash |
| Часть речи | Да (при редактировании, из списка) | Можно редактировать | AI или пользователь |
| Род существительного | Да для `sustantivo` | Можно редактировать | AI или пользователь |
| До 10 неверных русских вариантов | ≥3 | Можно редактировать | AI или пользователь |
| До 10 неверных испанских вариантов | ≥3 | Можно редактировать | AI или пользователь |

Четвёртый вариант для задания не хранится как неверный:

- в задании `испанский → русский` правильным четвёртым вариантом является основной русский перевод;
- в задании `русский → испанский` правильным четвёртым вариантом является испанский текст карточки.

В интерфейсе четыре ответа всегда перемешиваются.

## 3. Правила значений и дубликатов

### 3.1. Отдельное значение

Одна карточка описывает ровно одно изучаемое значение. Нельзя объединять в одной карточке два основных перевода.

Дополнительные переводы являются формулировками того же значения, а не другими значениями слова.

Корректно:

- основной перевод: `ждать`;
- дополнительные: `ожидать`, `дожидаться`.

Некорректно:

- основной перевод: `ждать`;
- дополнительный перевод: `надеяться`.

### 3.2. Определение дубликата

Дубликатом в пределах одного пользователя считается совпадение:

- испанского текста;
- основного русского перевода.

Для проверки удаляются пробелы в начале и конце, повторяющиеся пробелы заменяются одним, регистр не учитывается. Диакритические символы не удаляются: `n` и `ñ` различаются.

Проверка выполняется среди всех карточек пользователя, включая подготовленные карточки будущих уроков.

Совпадение нового основного перевода с дополнительным переводом существующей карточки считается предупреждением о возможном дубликате, но не блокирует создание автоматически: одинаковая формулировка может обозначать другое значение в другом контексте. Пользователь должен выбрать «Открыть существующую» либо явно подтвердить «Это другое значение».

Если дубликат найден:

1. новая карточка не создаётся;
2. пользователь получает сообщение;
3. открывается существующая карточка;
4. при добавлении из урока существующая карточка связывается с уроком.

Права на редактирование содержимого записи общей базы после сохранения:

| Кто | Что можно править |
|---|---|
| `admin` | любые слова |
| `teacher` | только слова, которые **он сам создал** (поиск или урок) |
| `user` | ничего (только просмотр, прогресс, сброс, удаление из словаря) |

У `user` нет создания курсов/уроков, поэтому правки контента нет. Изменение
полей (когда разрешено) применяется ко всем пользователям с этой карточкой.
Для другого значения того же испанского слова создаётся новая запись.

Роль `admin` дополнительно имеет каталог всех слов из меню аккаунта
(«Todas las palabras»):

- в шапке — поиск с suggestions (как на главной), но выбранная **новая**
  пара добавляется в **общую базу** (`Word` без личной `UserCard`); после
  сохранения — возврат в список каталога;
- уже существующая в БД пара открывается на edit из каталога;
- список: фильтр, сортировка по обновлению / добавлению, даты Act./Alta.

Подробности — [README.md](./README.md) §5.1; API —
[technical/words.md](../technical/words.md); квоты — §12 и
[technical/quotas.md](../technical/quotas.md).

## 4. Добавление самостоятельной карточки (поиск)

Предусловия: пользователь авторизован; направление по умолчанию
`испанский → русский`.

Добавление **существующей** пары из БД в словарь (`+` / existing) **не**
вызывает генерацию и **не** тратит квоту генераций.

Добавление **новой** пары через поиск различается по роли.

### 4.1. Роль `user`: автогенерация и сразу в словарь

1. Пользователь выбирает или вводит пару (через suggestions / ввод).
2. Система **до** вызова платных API проверяет дневную квоту генераций
   (§12). При исчерпании — ошибка квоты, слово не создаётся.
3. Сервер генерирует содержимое (OpenAI + Unsplash), создаёт `Word` +
   `UserCard`, при необходимости TTS (ElevenLabs) **только здесь**.
4. UI **не** показывает экран правки полей: карточку нельзя отредактировать
   на этом шаге (и позже — см. права в §3).
5. Пользователь попадает на просмотр карточки / словарь.

### 4.2. `admin` / `teacher`: полный мастер (preview → правка → сохранение)

1. Ввод испанского → поиск в своём словаре + известные пары БД + suggestions AI.
2. Выбор или ввод перевода (дубликат в своём словаре → сценарий дубликата,
   генерация не запускается).
3. Генерация содержимого AI одним ответом (определение, примеры, часть речи,
   род, неверные варианты, фраза Unsplash) и изображение Unsplash.
4. Редактируемая форма (как edit): правка полей, смена/реген картинки
   (с учётом лимита регенов §12), ручное заполнение если AI недоступен.
5. Сохранение: обязательные поля как при edit; источник «самостоятельно»;
   прогресс 0%; TTS при создании нового `Word`.

Admin не ограничен дневными квотами генераций/suggestions.

### 4.3. Добавление через урок курса

При создании слова **внутри урока курса** (создатель — `teacher`/`admin`)
поведение как у полного мастера с правкой формы (§4.2). Такая генерация
учитывается в квоте «курсы / total» (§12). После сохранения создатель-teacher
может править слово (§3).

Подробности уроков — [02-lessons.md](./02-lessons.md), курсы —
[05-courses.md](./05-courses.md).

## 5. Готовность к тренажёру

Карточка готова к полному тренажёру, если заполнены:

- испанский текст;
- основной русский перевод;
- не менее 3 уникальных неверных русских вариантов;
- не менее 3 уникальных неверных испанских вариантов.

В задании выбора из пула показываются 3 случайных неверных варианта и один правильный.

Изображение, определение и примеры улучшают вводную карточку, но не обязательны для допуска.

### Требования к неверным вариантам

1. Все три варианта одного направления уникальны без учёта регистра и лишних пробелов.
2. Неверный вариант не совпадает с правильным ответом.
3. Русский неверный вариант не может совпадать с дополнительным правильным переводом.
4. В рамках изучаемого значения неверный вариант не должен быть ещё одним правильным ответом.
5. Пустой вариант не принимается.

Интерфейс показывает статус «Готово к тренировке» или список отсутствующих/некорректных полей.

## 6. Просмотр карточки

Карточка показывает:

- испанский текст;
- основной и дополнительные переводы;
- изображение и атрибуцию;
- часть речи и род;
- определение;
- примеры;
- прогресс 0–100%;
- уроки, в которые она добавлена;
- статус готовности к тренажёру.

Доступные действия:

- воспроизвести испанский текст (из сохранённого `WordAudio`, без новой генерации TTS);
- воспроизвести примеры (если предусмотрено UI);
- изменить разрешённые поля — **только при праве** (§3 / §8);
- заменить/перегенерировать изображение — только при праве edit и с лимитом
  регенов (§12);
- сбросить прогресс;
- удалить карточку.

## 7. Аудио

1. TTS (ElevenLabs) выполняется **только при создании нового** `Word`
   (добавление через поиск или урок курса) и сохраняется в `WordAudio`.
2. Воспроизведение в карточке, тренажёре и `GET /speech` читает уже
   сохранённый mp3. **Повторная генерация TTS запрещена** (нет lazy ensure
   в trainer / speech).
3. Если аудио отсутствует — показать ошибку/тишину без вызова ElevenLabs.
4. Отдельная дневная квота TTS не нужна: генерация речи входит в путь
   добавления слова, ограниченный квотой генераций (§12).

## 8. Редактирование

Иконка карандаша на `/words/:cardId` только при праве из §3
(`admin` или `teacher` для слова, которое он создал).
Иначе иконки нет; прямой `/edit` отклоняется (`403`).

`admin` также правит из каталога всех слов без своей `UserCard`.

Можно редактировать:

- основной русский перевод (изменение пишется в общий `Word` и видно всем
  пользователям с этой карточкой);
- определение;
- примеры (≥2);
- часть речи (выпадающий список) и род (только для `sustantivo`);
- URL и атрибуцию изображения;
- пул неверных вариантов каждого направления (3–10).

Нельзя редактировать испанский текст.

При смене русского перевода система проверяет уникальность пары
`(испанский, русский)`. Конфликтующее изменение не сохраняется (`409`).

Сохранение на экране редактирования требует заполнения обязательных полей
(перевод, определение, ≥2 примеров, категория, род для существительного,
≥3 неверных варианта в каждую сторону). Изображение необязательно.

Перегенерация изображения («Otra imagen») учитывает текущий перевод в форме,
заменяет превью URL и атрибуцию; в БД попадает только после «Guardar».
На одно слово допускается **не более 3** успешных генераций картинки суммарно
(create + регены, включая admin). Четвёртая попытка — ошибка без вызова
внешних API.

## 9. Удаление и сброс прогресса

### 9.1. Удаление

Перед удалением показывается подтверждение с предупреждением. После подтверждения карточка:

- удаляется из личного словаря;
- удаляется из всех уроков пользователя;
- больше не участвует в будущих подборках;
- исключается из ещё не начатых тренажёров с дополнением по правилам соответствующей подборки, если подходящая замена существует.

Если карточка присутствует в уже начатом тренажёре, тренажёр прекращается и при следующем запуске начинается заново. Прогресс незавершённого запуска не учитывается.

Удаление пользовательской карточки не удаляет обезличенную пару перевода из общей базы, если она используется другими карточками.

### 9.2. Сброс прогресса

Сброс требует подтверждения и устанавливает прогресс карточки в 0%. Дата последней тренировки и агрегатные счётчики сохраняются. Состав уже созданных ежедневных подборок не меняется.

## 10. Ошибки и пограничные случаи

| Ситуация | Поведение |
|---|---|
| AI недоступен при поиске переводов | Показать переводы БД и ручной ввод |
| AI недоступен при генерации карточки | Оставить поля пустыми, разрешить ручное заполнение и повтор |
| AI вернул невалидную структуру | Не переносить сомнительные значения в форму; показать ошибку повтора |
| Unsplash недоступен | Разрешить URL вручную или карточку без изображения |
| URL изображения не открывается | Показать заглушку и действия замены |
| Пользователь дважды отправил форму | Создать не более одной карточки |
| Найден дубликат | Не создавать новую карточку, открыть существующую |
| Нет `WordAudio` | Воспроизведение без TTS; не генерировать |
| Дневная квота генераций / suggestions исчерпана | Ошибка квоты до внешних API |
| 4-я генерация картинки на слово | Ошибка без внешних API |
| AI предложил два правильных ответа среди вариантов | Не считать карточку готовой, потребовать исправить варианты |

## 11. Критерии приёмки

- **WORD-01:** пустой испанский текст нельзя отправить на следующий шаг.
- **WORD-02:** варианты из БД отображаются раньше вариантов AI (admin / suggestions).
- **WORD-03:** можно выбрать предложенный или ввести собственный перевод.
- **WORD-04:** дубликат не создаётся и открывается существующая карточка.
- **WORD-05:** разные основные значения одного испанского текста — отдельные записи.
- **WORD-06:** генерация содержимого — один структурированный AI-ответ (+ Unsplash).
- **WORD-07:** сбой AI/Unsplash: admin/курс могут дозаполнить вручную; non-admin
  search auto-add при полном провале генерации — понятная ошибка/повтор.
- **WORD-08:** edit только у admin (любые) или teacher (свои); у user нет UI правки.
- **WORD-09:** пул неверных вариантов; в задании 3 случайных + правильный.
- **WORD-10:** четыре ответа перемешиваются при каждом задании.
- **WORD-11:** неполная карточка видна в словаре, но не в полном тренажёре.
- **WORD-12:** Unsplash-изображение — URL с атрибуцией.
- **WORD-13:** воспроизведение из сохранённого `WordAudio`; TTS только при create.
- **WORD-14:** генераций картинки ≤ 3 на слово за жизнь записи (create + регены).
- **WORD-15:** сброс прогресса → 0%, карточка остаётся.
- **WORD-16:** удалённая карточка не участвует в уроках и подборках.
- **WORD-17:** admin — каталог; suggestions в шапке добавляют в общую базу
  без личного словаря; после save — список; existing → edit; правка любой
  записи; фильтр/сортировка/даты в списке.
- **WORD-18:** non-admin поиск — auto-add без экрана правки.
- **WORD-19:** дневные квоты gen/suggestions для не-admin; override в БД.

## 12. Квоты платных вызовов

День — `Europe/Madrid`. Подробная техническая спецификация —
[technical/quotas.md](../technical/quotas.md).

| Квота | `user` | `teacher` | `admin` |
|---|---:|---:|---|
| Генерация слов (поиск или урок, один счётчик) | 30/день | 100/день | без лимита |
| Suggestions (OpenAI) | 300/день | 600/день | без лимита |
| Генерации картинки на одно слово | ≤3 суммарно | ≤3 | ≤3 |

На `User` nullable override: `dailyGenerationLimit`,
`dailySuggestionsLimit` (`null` = дефолт по роли).

При исчерпании — ошибка «дневная квота закончена» **до** вызова OpenAI /
Unsplash / ElevenLabs. `admin` без дневных квот gen/suggestions.

### Лимиты полей пары и suggestions

| | Испанский | Русский |
|---|---|---|
| Макс. слов | 10 | без ограничений |
| Макс. символов | 100 | 120 |
| Мин. символов | 1 | 1 |

«Слово» = токен после trim и схлопывания пробелов. Те же лимиты для
основной пары при create/edit и для `GET /suggestions?q` (по направлению
ввода).
