# Colecciones — наборы слов

## 1. Цель

**Colección** — именованный набор слов из общего каталога, который
администратор готовит для пользователей. Пользователь может добавить
коллекцию к себе: все её слова попадают в личный словарь, появляется
прогресс по набору и прямой запуск тренировки (до 12 слов).

Интерфейс на испанском. Пункт меню аккаунта: **Colecciones** (все
авторизованные роли). Создавать и править коллекции может только `admin`.

Слова и карточки — [01-words.md](./01-words.md); ежедневные тренажёры —
[03-daily-training.md](./03-daily-training.md); прохождение тренажёра —
[04-word-trainer.md](./04-word-trainer.md). Технический каркас —
[technical/collections.md](../technical/collections.md).

## 2. Термины

### Colección

Админский набор: название + упорядоченный список ссылок на существующие
записи `Word` общего каталога. Не является курсом и не имеет уроков.

### Добавленная коллекция (membership)

Связь «пользователь добавил эту коллекцию к себе». Пока membership есть,
коллекция показывается в блоке «мои» с прогрессом и кнопкой тренировки.

### Принесённое слово

Слово, которое попало в личный словарь **именно при добавлении этой
коллекции** (или при последующем автодобавлении нового слова состава
подписчику), а до этого у пользователя карточки этого `Word` в словаре
не было. Учитывается при снятии коллекции пользователем.

Слово, которое уже было в словаре (поиск, курс, другая коллекция) до
добавления текущей, **не** считается принесённым этой коллекцией.

## 3. Роли и меню

| Роль | Доступ |
|---|---|
| `user` / `teacher` | Список, поиск, add/remove, деталка, тренировка своих |
| `admin` | То же + создание / правка названия / состав / удаление коллекции |

В меню аккаунта один пункт **Colecciones** для всех. У `admin` на экранах
списка и детали доступны действия управления; отдельный пункт «Gestión»
не обязателен.

`teacher` **не** создаёт и не редактирует коллекции.

## 4. Данные коллекции (админ)

Коллекция содержит:

- уникальный идентификатор;
- название (обязательно после trim);
- **статус** (см. §4.1);
- упорядоченный список слов из общего каталога;
- даты создания / обновления.

### 4.1. Статусы

| Статус | Смысл | Видят пользователи |
|---|---|---|
| `created` | черновик при создании | нет (только admin) |
| `ready` | опубликована | да (каталог / add / train) |
| `inactive` | снята с публикации | нет (только admin) |

Переходы (только admin):

- `created` → `ready` — только если в составе ≥1 слово;
- `ready` → `inactive`;
- `inactive` → `ready` — только если в составе ≥1 слово;
- `created` → `inactive` — допустимо.

При переходе **в `inactive`** (с любого статуса):

- membership и provenance по коллекции удаляются у всех;
- слова в словарях **остаются** (как при удалении коллекции админом);
- коллекция пропадает из «моих» и каталога у пользователей.

### Ограничения состава

1. В набор попадают существующие `Word` из suggestions либо новые через
   форму создания (каталог + сразу item коллекции).
2. Одно и то же `Word` не дублируется в одной коллекции.
3. Пустая коллекция допустима в `created` / `inactive`; опубликовать
   (`ready`) с 0 словами нельзя.
4. Пока статус `ready`, нельзя удалить последнее слово (в составе
   всегда ≥1).
5. Порядок слов в наборе задаёт админ (отображение на деталке).

### Действия админа

- создать коллекцию (название, статус `created`);
- изменить название;
- сменить статус (публикация / деактивация);
- добавить слово через **поиск suggestions** на странице коллекции
  (как в уроке): существующая пара — сразу в набор; новая — форма
  `/words/new?collectionId=…`, после save возврат в коллекцию;
- удалить слово из коллекции (с ограничением для `ready`);
- удалить коллекцию целиком.

## 5. Синхронизация состава с подписчиками

Состав коллекции **live**: UI «моих» и деталка всегда отражают текущий
админский набор. Подписчики бывают только у `ready`.

| Событие | Membership | Словарь подписчиков |
|---|---|---|
| Админ **добавил** слово в коллекцию | без изменений | слово **автодобавляется** в словарь каждого подписчика: если карточки не было — `source = manual`, progress 0%, слово помечается **принесённым** этой коллекцией; если уже была — не трогаем |
| Админ **убрал** слово из коллекции | без изменений | слово **остаётся** в словаре; на деталке коллекции больше не показывается |
| Админ перевёл в **`inactive`** | membership + provenance удаляются у всех | слова **остаются** в словарях |
| Админ **удалил** коллекцию | membership удаляется у всех | слова **остаются** в словарях (в т.ч. принесённые без тренировок) |

Уже сформированные ежедневные подборки дня **не** перестраиваются из‑за
этих событий (как при обычном добавлении слов).

## 6. Пользовательский список

Страница **Colecciones**:

1. **Сверху — добавленные** (если есть): только `ready` с membership;
   название, прогресс, тренировка, переход в деталку.
2. **Ниже — каталог** остальных **`ready`**: названия / число слов;
   поиск; «добавить». Добавленные в каталоге не показываются.
3. У **admin** дополнительно блок черновиков / неактивных
   (`created` / `inactive`) — не в пользовательском каталоге.

`created` / `inactive` пользователям в списке и по прямому URL не
отдаются (`404`). Admin видит любые статусы.

Пустые состояния: нет `ready` коллекций; нет совпадений поиска; у
пользователя ещё нет добавленных.

## 7. Добавление коллекции к себе

Предусловие: пользователь авторизован; коллекция **`ready`**; membership
ещё нет.

1. Создаётся membership.
2. Для каждого слова текущего состава:
   - если у пользователя уже есть карточка этого `Word` в словаре —
     **ничего не меняем** (progress, `source`, `addedAt`, счётчики);
   - иначе создаём карточку в словаре: `source = manual`, `inDictionary =
     true`, progress 0%, помечаем как **принесённое** этой коллекцией.
3. Генерация AI / TTS / квоты **не** вызываются: используются готовые
   записи каталога.
4. Коллекция исчезает из каталога списка и появляется в блоке «мои».

Добавление идемпотентно: повторный add при уже существующем membership
не дублирует карточки.

## 8. Снятие коллекции пользователем

Требует подтверждения.

1. Membership удаляется; коллекция возвращается в каталог списка.
2. Для каждого слова, которое было **принесено этой коллекцией** и у
   которого `completedTrainerCount = 0`: карточка удаляется из личного
   словаря (те же последствия, что у обычного удаления карточки:
   [01-words.md](./01-words.md) §9.1 — не участвует в будущих подборках;
   незавершённый тренажёр с этой карточкой прерывается).
3. Слова, которые уже были в словаре до добавления коллекции (поиск /
   курс / другая коллекция), **остаются** всегда — даже без тренировок.
4. Слова с `completedTrainerCount > 0` остаются в словаре вместе с
   прогрессом.
5. Если то же принесённое слово всё ещё нужно другой **добавленной**
   коллекцией пользователя, карточку **не** удаляем (слово остаётся
   принесённым оставшимися коллекциями / просто в словаре).

Состав уже созданных ежедневных подборок не пересобирается; перед
стартом незавершённого тренажёра действуют обычные правила замены
удалённых карточек.

## 9. Детальная страница

Показывает:

- название;
- для добавленной — прогресс коллекции и действие тренировки / снять;
- для не добавленной — действие добавить;
- список слов состава: испанский текст, основной перевод, прогресс
  карточки пользователя (0%, если слова ещё нет в словаре — только до
  add; после add у подписчика карточка есть), статус готовности к
  тренажёру;
- у `admin` — правка названия и состава.

Переход к карточке слова — если она есть в словаре пользователя.

## 10. Прогресс коллекции

Прогресс коллекции для пользователя — **среднее арифметическое**
`progress` по всем словам **текущего** состава, для которых у
пользователя есть карточка в словаре.

- Если карточек по составу 0 (пустая коллекция или ещё не добавлена) —
  прогресс не показываем или показываем как недоступный.
- Слова состава без карточки у не‑подписчика в среднее не входят;
  у подписчика после sync карточки есть у всех слов состава.
- Округление для UI — до целого процента (обычное арифметическое
  округление).

Это отображаемый агрегат; в алгоритм ежедневных слотов отдельно не
входит.

## 11. Прямой запуск тренировки коллекции

Доступен только для **добавленной** коллекции (список «мои» и деталка).

Правила (аналог урока, лимит как у daily):

1. Берутся только карточки слов **текущего** состава, которые есть в
   словаре пользователя и **готовы** к полному тренажёру
   ([01-words.md](./01-words.md) §5).
2. Если готовых больше 12 — для одного запуска выбираются **12** с
   приоритетом: меньший progress → более давний `lastTrainedAt`
   (никогда не тренировавшиеся раньше) → меньший `showCount` →
   случайно при полном равенстве.
3. Если готовых 1–12 — используются все.
4. Если готовых 0 — запуск блокируется; UI показывает, что нет слов,
   готовых к тренировке.
5. Упражнения и изменение progress — как у обычного тренажёра
   ([04-word-trainer.md](./04-word-trainer.md), [03-daily-training.md](./03-daily-training.md) §3).
6. Intro-карточки — только для `completedTrainerCount = 0`.

Лимиты для сравнения:

| Источник запуска | Макс. слов за запуск |
|---|---:|
| Ежедневный / extra | 12 |
| Colección | 12 |
| Урок курса | 10 |

## 12. Связь с ежедневными тренажёрами

Карточки, **впервые** попавшие в словарь через коллекцию, имеют
`source = manual` и участвуют в ежедневных пулах **наравне** со словами,
добавленными через поиск:

- при наличии урокового окна: Manual ∩ Recent-14 в слотах 1–2; Age&lt;28 и
  Unstarted — по общим правилам;
- без урокового окна: те же пять категорий самостоятельных карточек.

### Приоритет относительно курсов

1. Добавление коллекции **не понижает** уже существующий `source =
   lesson` и не меняет прогресс.
2. Если то же слово входит в окно уроков эффективно активного курса
   (`inCurrentLesson` / `inRecentLessons`), в ежедневных слотах действует
   **уроковый** приоритет, как для любой карточки словаря из урока.
3. Direct trainer коллекции не подменяет daily/extra и не меняет правила
   весов extra.
4. Перепроверка: слоты 1–5 и extra используют одни и те же поля
   (`source`, флаги урока, progress, даты); коллекция не вводит отдельный
   `UserCardSource`. Расхождения лимитов — только у прямого запуска
   урока (10) vs коллекции/daily (12).

Подробности пулов — [03-daily-training.md](./03-daily-training.md).

## 13. Ошибки и пограничные случаи

| Ситуация | Поведение |
|---|---|
| Не-admin create/update/delete коллекции | `403` |
| Add к не-`ready` | `404` / запрет |
| Add уже добавленной | Идемпотентный успех / no-op |
| Remove без membership | Ошибка / no-op |
| Publish (`ready`) при 0 словах | Запрещено |
| Удаление последнего слова при `ready` | Запрещено |
| Деактивация (`inactive`) | Membership + provenance сняты; словари без чистки |
| Админ удалил коллекцию | Membership у всех снят; словари без чистки |
| Админ убрал слово из набора | Слово исчезает из UI коллекции; словарь без изменений |
| Админ добавил слово подписчикам | Автоadd в словарь; уже существующие карточки не трогаем |
| `ready` с 0 готовых к тренажёру | Add возможен; train заблокирован |
| Слово удалено из каталога (если когда‑либо допустимо) | Не оставлять «битых» ссылок в составе; поведение удаления `Word` — вне этого документа, пока запрещено при наличии ссылок |
| Прерванный trainer коллекции | Progress не меняется; следующий запуск с начала |
| Принесённое слово также в другой моей коллекции | При снятии одной коллекции карточку не удаляем |

## 14. Критерии приёмки

- **COLL-01:** пункт меню **Colecciones** виден всем авторизованным.
- **COLL-02:** создавать / менять состав / статус / удалять коллекции
  может только `admin`; `teacher` и `user` — нет.
- **COLL-02b:** create → `created`; `ready` только при ≥1 слове;
  `inactive` снимает membership/provenance, словари целы; пользователи
  видят только `ready`.
- **COLL-02c:** при `ready` нельзя удалить последнее слово.
- **COLL-03:** в каталоге списка видны только ещё не добавленные
  **`ready`** коллекции; поиск по названию.
- **COLL-04:** добавленные показываются отдельным блоком сверху с
  прогрессом (среднее по словам состава в словаре).
- **COLL-05:** add добавляет отсутствующие слова в словарь как `manual`
  с пометкой принесённых; существующие карточки не изменяет.
- **COLL-06:** remove membership удаляет из словаря только принесённые
  этой коллекцией с `completedTrainerCount = 0`; ранее бывшие в словаре
  слова сохраняются.
- **COLL-07:** удаление коллекции админом снимает membership у всех и
  **не** чистит словари.
- **COLL-08:** удаление слова админом из состава не чистит словари;
  добавление слова в состав автодобавляет его подписчикам.
- **COLL-09:** деталка показывает слова состава и progress карточек.
- **COLL-10:** train только для добавленной; до 12 готовых; приоритет
  progress → давность → показы; при 0 готовых — блок.
- **COLL-11:** новые карточки из коллекции в daily = как search
  (`manual`); `lesson` и уроковые флаги не понижаются.
- **COLL-12:** AI/TTS/квоты при add коллекции не вызываются.
