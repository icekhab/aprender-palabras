# Продуктовая документация aprender-palabras

## 1. Назначение

`aprender-palabras` — mobile-first web-приложение для самостоятельного изучения испанских слов, словосочетаний и выражений с переводом на русский язык.

Пользователь:

1. создаёт карточки вручную или с помощью AI;
2. объединяет карточки в упорядоченные уроки;
3. получает до пяти ежедневных подборок с учётом уроков и прогресса;
4. проходит тренажёры;
5. видит и при необходимости сбрасывает прогресс каждого значения слова.

Версия 1 поддерживает только языковую пару с испанским текстом карточки и русским основным переводом. В самом тренажёре используются задания в обоих направлениях: `испанский → русский` и `русский → испанский`. Модель продукта не должна предполагать, что эта языковая пара останется единственной, однако выбор языков и другие пары не входят в интерфейс версии 1.

## 3. Термины

### Пользователь

Владелец личного словаря и прогресса. Данные одного пользователя недоступны
другим, кроме сценариев курса (только для `teacher` / `admin`) и прав
`admin` на общий каталог слов.

Роль пользователя:

- **`user`** — словарь и тренажёры без курсов; раздел Cursos недоступен;
- **`teacher`** — плюс создание / прохождение / приглашения по курсам;
- **`admin`** — права teacher по курсам + каталог и правка любых слов.

Аккаунты на текущем этапе создаются административно (миграции БД), без
самостоятельной регистрации в интерфейсе.

### Курс

Упорядоченный набор уроков со словами. Доступен только пользователям с ролью
`teacher` или `admin` (создание, просмотр, прохождение, приглашения).
Приглашать можно только других `teacher`/`admin`. Подробности —
в [05-courses.md](./05-courses.md).

### Карточка

Одно конкретное значение испанского слова, словосочетания или выражения. Разные значения одного написания являются разными карточками.

Пример: `esperar — ждать` и `esperar — надеяться` — две карточки.

### Личный словарь

Карточки, доступные пользователю для обычного просмотра и ежедневных тренажёров. Подготовленная карточка далёкого будущего урока ещё не входит в личный словарь.

### Самостоятельно добавленная карточка

Карточка, созданная вне урока. В алгоритмах также называется ручной или внеурочной карточкой. Использование AI при её заполнении не меняет этот тип происхождения.

### Подготовленная карточка урока

Карточка, созданная внутри урока. Она может использоваться при прямом запуске этого урока, но попадает в личный словарь только по правилам смены текущего урока.

### Текущий урок

Урок курса, отмеченный как последний пройденный **для конкретного участника
этого курса**. У одного пользователя может быть свой текущий урок в каждом
курсе, в котором он состоит. Все уроки того же курса перед текущим считаются
предыдущими, первый после него — следующим, остальные — будущими.

### Тренажёр

Зафиксированный набор из целевых карточек и последовательность заданий для них. Ежедневная подборка определяет карточки, а тренажёр — порядок их показа и проверки.

### Прогресс карточки

Целое значение от 0 до 100%, показывающее степень изученности конкретного значения слова данным пользователем.

## 4. Границы первой версии

### Входит

- вход и выход из аккаунта (аккаунты создаются миграциями / админом);
- роли `user`, `teacher`, `admin`;
- изоляция личных данных пользователей;
- общее хранилище пар слов; edit — `admin` любые / `teacher` свои / `user` нет;
- поиск: у `user` — auto-add без правки; у `teacher`/`admin` — форма;
  квоты генераций и suggestions (ещё в roadmap);
- каталог всех слов для admin (suggestions → add в общую базу без словаря);
  TTS только при create слова;
- адаптивный mobile-first интерфейс с полноценной компьютерной версией;
- добавление, просмотр, изменение разрешённых полей и удаление карточек;
- помощь AI при заполнении карточки;
- изображения Unsplash по URL;
- воспроизведение речи (см. техническую документацию);
- курсы только для `teacher`/`admin`: создание, уроки, `active`, invite
  других teacher/admin; accept/reject на Cursos без email;
- demotion создателя (потеря teacher/admin): курсы как деактивированные;
  слова уже в словаре учеников остаются в тренировках;
- завершение курса участником (current = последний или вручную);
- текущий урок на участника; создатель меняет current / complete у
  приглашённых; списки участников и всех приглашённых;
- прогресс карточек;
- до пяти ежедневных и дополнительные случайные тренажёры с учётом окон
  уроков всех активных курсов участника.

### Не входит

- самостоятельная регистрация в UI, подтверждение email, восстановление
  пароля и социальная авторизация;
- приглашение пользователей, которых ещё нет в системе;
- доставка приглашений по email / magic link;
- полноценная административная панель (кроме каталога слов для admin);
- доступ к курсам для роли `user` (в т.ч. как «ученик» без teacher);
- импорт списком;
- push/email-уведомления;
- аналитическая панель;
- другие языковые пары в пользовательском интерфейсе;
- загрузка копий изображений в собственное файловое хранилище;
- архивирование карточек.

## 5. Общие бизнес-правила

### 5.1. Авторизация и владение

1. Логин уникален без учёта регистра.
2. Пароль обязателен.
3. Пользователь видит и изменяет только свои личные карточки словаря, прогресс
   и настройки, кроме явно описанных исключений курса и роли `admin`.
4. Редактировать содержимое слова: `admin` — любые; `teacher` — только свои;
   `user` — не редактирует. Добавление через поиск у `user` — автогенерация
   без экрана правки; у `teacher`/`admin` — форма после генерации. У admin
   каталог: тот же поиск suggestions, но create только в общую базу
   (без `UserCard`), затем список каталога.
5. Из общей базы для подсказок разрешены обезличенные пары
   «испанский текст — русский перевод». Чужая статистика не раскрывается.
6. Создатель курса видит приглашённых и может менять их текущий урок /
   завершать курс; приглашённый не видит прогресс других.
7. Платные API ограничены дневными квотами для не-admin (генерации слов,
   suggestions) и лимитом регенов картинки на слово; TTS только при
   создании слова. См. [01-words.md](./01-words.md) §12 и
   [technical/quotas.md](../technical/quotas.md).

Требования к хранению пароля — в технической документации. Самостоятельная
регистрация в UI на этом этапе не реализуется.

### 5.2. Необязательные данные

Для сохранения карточки обязательны испанский текст и основной русский перевод. Остальные поля можно заполнить позже.

Неполная карточка показывается в словаре, но в полный тренажёр допускается только после заполнения данных, необходимых всем пяти упражнениям. Интерфейс должен показывать, каких данных не хватает.

### 5.3. Внешние сервисы

Недоступность AI или Unsplash: для admin / добавления в урок курса —
ручное сохранение обязательных полей где применимо; для non-admin auto-add
из поиска — понятная ошибка и повтор. Исчерпание квоты блокирует вызов
платного API.

Озвучка: ElevenLabs только при создании нового `Word`; воспроизведение —
из сохранённого `WordAudio` без повторной генерации.

Точный провайдер/модель OpenAI и ключи — в технической документации и env.

### 5.4. Даты

Все правила «сегодня», «последние 2 недели» и «последние 4 недели» вычисляются в часовой зоне `Europe/Madrid`:

- последние 2 недели — время добавления не раньше текущего момента минус 14 суток;
- последние 4 недели — время добавления не раньше текущего момента минус 28 суток;
- старше 2 недель — время добавления раньше границы 14 суток;
- старше 4 недель — время добавления раньше границы 28 суток.

Сравнение выполняется после приведения текущего времени и времени добавления к `Europe/Madrid`; момент ровно на границе входит в более новую категорию.

### 5.5. Курсы (кратко)

Уроки только внутри курсов. Раздел **Cursos** только у `teacher`/`admin`.
Роль `user` курсов не видит и не проходит. Приглашения — только между
teacher/admin. Demotion создателя → курсы эффективно деактивированы; карточки
уже в словаре продолжают участвовать в ежедневных тренировках. Подробности —
[05-courses.md](./05-courses.md).

## 6. Основные пользовательские маршруты

### Новый пользователь

1. Получает аккаунт (миграция) и входит.
2. Добавляет первую карточку и/или создаёт курс с уроками.
3. При наличии готовых карточек в словаре запускает тренажёр.
4. Отмечает текущий урок в курсе (для себя); при необходимости приглашает
   других пользователей на курс.
5. На следующий календарный день получает сохранённый набор ежедневных тренажёров.

### Добавление слова

`Испанский текст → варианты перевода из БД → варианты AI → выбор или ручной ввод перевода → генерация данных → проверка → сохранение`.

### Работа с курсами и уроками

`Создание курса → уроки и карточки → приглашение (если есть уроки) → подтверждение → выбор текущего урока участника → перенос карточек окна предыдущие + текущий + следующий в словарь`.

### Ежедневное обучение

`Открытие главной страницы → создание/загрузка ежедневных подборок → прохождение тренажёров → обновление прогресса → дополнительные случайные тренажёры`.

## 8. Общие состояния интерфейса

Каждый экран с загрузкой данных должен иметь состояния:

- первоначальная загрузка;
- успешная загрузка с данными;
- успешная загрузка без данных;
- ошибка с возможностью повторить безопасное действие;
- отправка формы с блокировкой повторной отправки;
- успешное сохранение;
- ошибка сохранения без потери введённых пользователем данных.

Опасные действия, включая удаление карточки и смену текущего урока с массовым добавлением слов, требуют подтверждения.
